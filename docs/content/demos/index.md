# Demos

This section collects short, runnable demo scenarios you can share with people who want a concrete starting point.

!!! info "How to use these demos"
    These pages are intentionally lightweight and illustrative.
    They use simplified, fictional, or demo-style examples to show what a TULIP workflow can look like in practice.
    Treat them as starter patterns for adaptation, not as official policy text, validated research methodology, or domain-specific guidance.

## Available Demos

- [Teaching support demos](teaching.md): content rewriting, policy-style workflow examples, and embedding search for course materials.
- [Research workflow demos](research.md): transcript analysis, codebook-assisted review, and embedding search examples.

Each demo page includes runnable commands and expandable code snippets so people can try the flow quickly and adapt it to their own context.
