#

![TULIP Logo](https://reit.tudelft.nl/img/project-tulip.png)

**TULIP** is TU Delft's LLM inference platform. It provides _OpenAI-compatible API_ access to selected locally hosted language models for research, education, and institutional applications. It is a pilot service jointly developed by REIT and ICT.

<!-- TULIP is intended for workflows such as AI-assisted coding, document analysis, and retrieval-augmented generation (RAG), embeddings, and application development. -->
