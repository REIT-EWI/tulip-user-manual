# TULIP Docs


![](https://reit.tudelft.nl/img/project-tulip.png)

**TULIP** is TU Delft's local LLM serving platform for research and education, powered by NVIDIA Dynamo and vLLM in the TULIP k8s cluster.

It exposes an **OpenAI-compatible API**, so any code written for the OpenAI client libraries will also work with TULIP.
