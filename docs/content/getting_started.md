# Getting Started

## API Endpoint

The TULIP API endpoint is available at:

```bash
https://api.tulip.tudelft.nl
```

Supported OpenAI-style endpoints:

- `/v1/responses`
- `/v1/chat/completions`

> Note: Authentication is not yet enabled!

## Available Models

TULIP serves multiple locally-hosted models, for example:

- `mistralai/Ministral-8B-Instruct-2410`: general-purpose assistant
- `Qwen/Qwen2.5-Coder-14B-Instruct`: coding-focused assistant
- `openai/gpt-oss-20b`: open-weights GPT-style model

The exact list may evolve overtime. You can query the currently active models at:

```bash
curl https://api.tulip.tudelft.nl/v1/models
```

Or, by simply visiting: [https://api.tulip.tudelft.nl/v1/models](https://api.tulip.tudelft.nl/v1/models)

## How to send requests

### Curl Example

Now, you can send a simple chat completion request like this:

```bash
curl https://api.tulip.tudelft.nl/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H 'Authorization: Bearer DUMMY_API_KEY' \
  -d '{
        "model": "mistralai/Ministral-8B-Instruct-2410",
        "messages": [
          {"role": "user", "content": "Say hello from TULIP."}
        ],
        "max_tokens": 64
      }'
```

### Python Example

With python, first, install the official OpenAI Python package, eg, using:

```bash
pip install openai
```

Then, you can send a simple chat completion request like this:

```python
from openai import OpenAI

client = OpenAI(base_url="https://api.tulip.tudelft.nl/v1", api_key="not-required-yet")

response = client.responses.create(
    model="mistralai/Ministral-8B-Instruct-2410",
    input="Write a one-sentence bedtime story about a unicorn."
)

print(response.output_text)
```

You can also see an array of content generated by the model in `response.output`.

```python
print(response.output)  # output can contain tool calls, data about reasoning tokens generated by reasoning models, and other items
```

## Limits (Pilot Phase)

- Some API features (e.g. images, audio, realtime) are not supported by the current backend stack (Dynamo / vLLM) or by the selected model (e.g. `gpt-oss-20b`).
- Streaming support varies per model.
- Model choice and configuration may change as the platform evolves. Always check the `/v1/models` endpoint for the latest list of available models.
- _Feedback is welcome and helps guide the next iteration of the platform._
